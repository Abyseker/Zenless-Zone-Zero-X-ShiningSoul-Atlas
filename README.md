# 绝区零X闪魂图鉴

闪魂 × 绝区零第二弹「仲夏欢梦」交互式卡牌收藏图鉴。主系列164款，活动与赠品14款，全部使用提供的截图卡面。

## 使用

- 点击分类：按稀有度、角色或阵营逐组排列，可选择单独一个分类。
- 点击卡面：未收集 → 已收集 → 已入库 → 未收集。
- 灰色代表未收集，截图原色代表已收集，卡面打勾代表已入库。
- 长按约550毫秒、点击左上角数量，或聚焦卡面后按F2，可填写0至9999份。
- 未收集为0份，进入持有状态至少为1份；已收集与已入库之间切换保留份数。
- 多角色卡片可以显示在不同行，所有位置共用状态和份数。

## 保存记录

收集记录直接保存在当前浏览器的第一方Cookie `zzz_shining_collection_v1` 中，并保留localStorage本机备份。Cookie有效期一年，每次修改续期。不需要注册，不上传收集记录至服务器。

不同浏览器、设备、隐私窗口和域名分别保存，不会自动跨设备同步。清理浏览器数据可能清除记录；通过右上角菜单导出JSON备份，也可导入恢复。

Cookie采用固定v1图鉴索引压缩保存；后续更新必须保持现有卡牌索引不变，仅在末尾追加新卡。

## 本地运行

需要Node.js 22.13或更新版本。

```sh
npm ci
npm run dev
npm test
npm run build
```

默认开发地址以终端输出为准。`dist/`为纯静态构建结果，可部署至GitHub Pages等静态托管服务，不需要后端数据库。

## GitHub Pages

仓库的 `docs/` 包含已构建网页。在仓库Settings → Pages中选择Deploy from a branch，分支main，目录/docs。提交docs更新后，GitHub Pages会自动发布。资源使用相对路径，支持项目子路径。

修改源代码后运行 `npm run build`，将dist内容同步至docs（不含.openai目录）并提交即可更新网页。

## 主要文件

- `app/Album.tsx`：图鉴、分类、点击与长按交互。
- `app/model.ts`：状态、份数和分类规则。
- `app/cookie-storage.ts`：Cookie编码、解码和校验。
- `app/data/cards.json`：卡号、名称、辅助角色/阵营标签及截图定位。
- `public/cards/`：178张截图裁切卡面。
- `web/`、`vite.static.config.ts`：静态网页入口及构建配置。
- `tests/`：三态、份数边界、分组、图片及Cookie容量校验。
